# PM Store — v2 (واجهة + باك إند مربوط)

## ما تم تنفيذه (حسب طلبك)

### 1. ربط الواجهة الخلفية
- كل صفحات `index.html` و `admin.html` تتصل الآن بـ `server.js` عبر `/api/*`
- التوكن JWT يُحفظ **في الذاكرة فقط** (ليس localStorage) — مطابق للتوصية الأمنية
- جميع العمليات (منتجات/طلبات/محافظ/إعدادات) تمر عبر API مع التحقق

### 2. الدومين والسيرفر — إصلاح
- السيرفر يخدم الملفات الثابتة (`express.static`) — لا تحتاج فصل
- `.env` و `.env.example` جاهزان — اضبط `ALLOWED_ORIGINS` لدومينك الحقيقي
- `GET /api/health` للمراقبة
- دليل النشر في `SETUP-GUIDE.md` (أصلحنا التعليمات)

### 3. صفحة الإدارة — إعادة بناء كاملة
- **المنتجات**: إضافة/تعديل/حذف + رفع **صور متعددة (حتى 5)** Base64 من الأدمن، معاينة فورية
- **المحافظ اليمنية**: CRUD كامل — الافتراضية: **جيب / جوالي / بنك الكريمي** + يمكن إضافة **ون كاش، فلوسك، وأي محفظة يمنية** وتعديلها
- **مكان ظهور المحافظ**: toggles للتحكم هل تظهر في **صفحة الأصناف** و **أسفل الصفحة (الفوتر)** و **صفحة الدفع**
- **تمويل الإعلانات من مكان واحد**: واجهة لشحن الرصيد لـ Meta / TikTok / Google / Snapchat عبر `POST /api/ads/fund`
- **إدارة المستخدمين**: إضافة عدة أشخاص (`super_admin` / `admin` / `editor`) والتحكم في التفعيل/الحذف
- **اللغات**: العربية/الإنجليزية قابلة للتعديل من الإعدادات
- **العملات**: تعدد العملة (YER / SAR / USD) مع rate قابل للتعديل من الأدمن
- **السوشيال**: حقول لفيسبوك/انستجرام/تيك توك/واتساب + Meta Pixel + TikTok Pixel

### 4. الواجهة الأمامية (index.html)
- زر **العربية / EN** — يقلب `dir="rtl/ltr"` وكل النصوص
- **محول العملة** YER/SAR/USD — السعر يحسب مباشرة
- **المحافظ** تظهر تلقائياً في قسم خاص + الفوتر + سلة الدفع (اختيار المحفظة عند الدفع)
- **السوشيال**: أيقونات فيسبوك/انستجرام/تيك توك/واتساب تُملأ من الإعدادات
- **Meta/TikTok Pixel** يُحقن تلقائياً إذا وضعت الـ ID في الإعدادات
- **واتساب عائم** + زر في الهيرو برقم **+967775201234** (محدث في كل مكان)
- صور المنتجات الحقيقية تظهر إن وجدت، وإلا أيقونة افتراضية

### 5. رقم الهاتف
- تم تغييره في كل المواضع إلى **+967775201234** (الهيدر، الفوتر، الإعدادات، واتساب)

## التشغيل محلياً
```bash
npm install
npm start
# افتح http://localhost:4000
# الإدارة: http://localhost:4000/admin.html
# دخول: admin@pmstore.com / Admin12345
```

## النشر
- ارفع المجلد كاملاً إلى Render/Railway/Fly.io
- اضبط متغيرات البيئة من `.env.example`
- اربط الدومين: `pmstore.com` → خدمة الاستضافة، `api.pmstore.com` → نفس السيرفر (يخدم الكل)
- HTTPS تلقائي

## ملاحظة أمان
- غيّر `JWT_SECRET` و `ADMIN_PASSWORD_HASH` في الإنتاج
- اضبط `ALLOWED_ORIGINS` لدومينك فقط (لا تترك `*`)
- البيانات in-memory — بدّلها بقاعدة بيانات (Postgres/Mongo) قبل الإنتاج الفعلي
